**Contract Version:** `1.0.0`  
**Phase:** 7 — RAG vs. Non-RAG Experimental Evaluation  
**Date:** September 2026  
**Status:** Canonical Experiment Specification  

---

## 1. Experimental Objective & Hypothesis

This contract formalizes the experimental protocol for isolating and measuring the impact of **retrieval-augmented evidence grounding** on clinical trial eligibility reasoning.

- **Hypothesis (H1 / H6):** Evidence-grounded RAG reasoning significantly reduces hallucinated eligibility assertions and increases grounded decision accuracy compared to non-retrieval reasoning, while safely routing missing information to `UNKNOWN`.
- **Primary Comparison:**
  - **Condition E5 (Non-RAG Baseline):** LLM/rule reasoning using patient clinical facts and criterion text without retrieval-augmented evidence passages.
  - **Condition E6 (RAG-Grounded Reasoner):** LLM/rule reasoning augmented with trial-level and criterion-level retrieved evidence passages and provenance metadata.

## 2. Information Boundaries & Anti-Leakage Protocol

```text
                                  +---------------------------------------+
                                  |         PATIENT CLINICAL DATA         |
                                  |  (Demographics, Facts, Patient Note)  |
                                  +-------------------+-------------------+
                                                      |
                                    +-----------------+-----------------+
                                    | Identical Input                   | Identical Input
                                    v                                   v
+---------------------------------------------------+   +---------------------------------------------------+
|               E5: NON-RAG BASELINE                |   |                E6: RAG-GROUNDED                   |
|---------------------------------------------------|   |---------------------------------------------------|
| - Patient Profile: INCLUDED                       |   | - Patient Profile: INCLUDED                       |
| - Criterion Definitions: INCLUDED                 |   | - Criterion Definitions: INCLUDED                 |
| - Retrieved Trial Passages: FORBIDDEN             |   | - Retrieved Trial Passages: INCLUDED              |
| - Retrieval Scores / Rankings: FORBIDDEN          |   | - Retrieval Scores / Rankings: INCLUDED           |
| - Reranker Scores: FORBIDDEN                      |   | - Reranker Scores: INCLUDED                       |
| - Pre-selected Retrieval Spans: FORBIDDEN         |   | - Pre-selected Retrieval Spans: INCLUDED          |
+---------------------------------------------------+   +---------------------------------------------------+
```

### 2.1 Information Leakage Invariants
1. **No Hidden Retrieval Leakage to Non-RAG:** E5 must never receive candidate trial brief summaries, retrieved criterion rankings, vector similarities, BM25 scores, or pre-filtered snippet alignments generated by the Phase 5 retrieval engine.
2. **No Patient Fact Asymmetry:** E6 must never receive any patient clinical fact, demographic attribute, or clinical note section that is withheld from E5.
3. **Identical Task Representation:** Both conditions evaluate the identical list of criteria in the exact same ordinal sequence.
4. **Identical Downstream Rules:** Both conditions use the identical Phase 6 deterministic aggregator (`scripts/eligibility_aggregator.py`) and validator (`scripts/validate_eligibility.py`).

| **Criterion Ordering** | Verbatim ascending criterion ID | Verbatim ascending criterion ID | Strictly Identical |
| **Decision Policy** | 3-valued (`PASS`, `FAIL`, `UNKNOWN`) | 3-valued (`PASS`, `FAIL`, `UNKNOWN`) | Strictly Identical |

## 6. Phase 5 Retrieval Engine Direct Invocation Protocol

In the updated architecture, RAG conditions directly invoke the Phase 5 retrieval engine:

```text
RAGExperimentRunner
        │
        ▼
Phase 5 Retriever (DenseRetriever / HybridRRFRetriever / RerankingRetriever)
        │
        ▼
Retrieved Candidate/Evidence Records (RetrievalResponse / RetrievalResult)
        │
        ▼
RAG Reasoning Context & Evidence Citations (source_field = "{retrieval_method}:{source_reference}")
        │
        ▼
Phase 6 Eligibility Reasoner (RuleBasedEligibilityReasoner)
        │
        ▼
Phase 6 Validator & Deterministic Aggregator (EligibilityValidator & EligibilityAggregator)
```
