## 1. Principles of Epistemic Grounding

Clinical trial matching systems operate in high-stakes healthcare domains where ungrounded assumptions or fabricated clinical facts can lead to inappropriate trial enrollment or unjustified denial of therapeutic options.

The **Phase 8 Grounding Policy** governs how clinical propositions generated by MedMatch reasoners are evaluated against verified source evidence. The policy is built upon four foundational tenets:

1. **Strict Evidential Entailment:** A clinical proposition is only accepted as `SUPPORTED` if it is directly entailed by verified patient facts, documented clinical notes, or candidate trial protocol documents.
2. **Preservation of Epistemic Ignorance:** An unmentioned clinical concept cannot be inferred as absent. Silence $\neq$ negation.
3. **Rigorous Rejection of Paraphrase Drift:** Clinical terminology variations must preserve exact disease stages, biomarker mutations, and numerical boundaries.
4. **Mandatory Provenance Fidelity:** A statement is not faithful if it cites a real fact with wrong offsets, wrong criterion IDs, or corrupted retrieval metadata.

## 2. Canonical Support Status Definitions

Every extracted claim is evaluated into exactly one of five [`SupportStatus`](file:///c:/Developers/Sneha/Projects/MEDMATCH_V2/scripts/grounding_schema.py#L22-L28) states:

```text
+----------------------------------------------------------------------------------------------------+
|                                    EVIDENCE SUPPORT POLICY MATRIX                                  |
+-----------------------+----------------------------------------------------------------------------+
| Status                | Operational Criterion                                                      |
+-----------------------+----------------------------------------------------------------------------+
| SUPPORTED             | Directly and fully entailed by available verified evidence. All entities,  |
|                       | assertions, numbers, and temporal constraints match source data.           |
+-----------------------+----------------------------------------------------------------------------+
| PARTIALLY_SUPPORTED   | One component is entailed by evidence, but a subordinate qualifier         |
|                       | (e.g. stage, frequency, histology) is unmentioned or unverified.           |
+-----------------------+----------------------------------------------------------------------------+
| UNSUPPORTED           | No available evidence mentions or entails the claim. The assertion is      |
|                       | an undocumented hallucination ($H1, H2, H3, H4$) or speculative inference. |
+-----------------------+----------------------------------------------------------------------------+
| CONTRADICTED          | Available evidence directly and explicitly conflicts with the claim        |
|                       | (e.g. asserted PRESENT when documented ABSENT; numerical discrepancy).     |
+-----------------------+----------------------------------------------------------------------------+
| INSUFFICIENT_EVIDENCE | The reasoning asserts that evidence is lacking, or the evidence is hedged  |
|                       | and insufficient to establish truth (valid justification for UNKNOWN).     |
+-----------------------+----------------------------------------------------------------------------+
```

## 3. Strict Boundary Distinctions

### 3.1 Unsupported vs. Contradicted vs. Missing Evidence

It is critical to distinguish between lack of evidence and positive evidence of absence:

- **Case 1: Missing Evidence $\implies$ `INSUFFICIENT_EVIDENCE` / `UNKNOWN`**
  - *Patient Record:* No mention of brain metastases.
  - *Generated Reasoning:* "Brain metastasis status is not documented in the clinical record; status cannot be determined."
  - *Policy:* **SUPPORTED** or **INSUFFICIENT_EVIDENCE** (valid epistemic abstention).
- **Case 2: Missing Evidence but Asserted Present $\implies$ `UNSUPPORTED` ($H1$)**
  - *Patient Record:* No mention of brain metastases.
  - *Generated Reasoning:* "Patient has documented brain metastases."
  - *Policy:* **UNSUPPORTED**. Fabricated clinical fact.
- **Case 3: Documented Absence but Asserted Present $\implies$ `CONTRADICTED` ($H6$)**
  - *Patient Record:* "MRI brain: negative for intracranial metastases" (assertion: `ABSENT`).
  - *Generated Reasoning:* "Patient has brain metastases."
  - *Policy:* **CONTRADICTED**. Direct factual contradiction.
- **Case 4: Documented Absence Treated as Missing $\implies$ `CONTRADICTED` / `EVIDENCE_OMISSION` ($H9$)**
  - *Patient Record:* Documented negative for brain metastases.
  - *Generated Reasoning:* "No information regarding brain metastases is available; status is unknown."
  - *Policy:* **CONTRADICTED** / **EVIDENCE_OMISSION**. Fails to recognize existing negative evidence.

## 4. Preservation of Phase 6 Clinical Semantics

The Phase 8 grounding evaluation enforces strict preservation of the clinical decision-support semantics established in Phase 4 and Phase 6:

### 4.1 Negation Integrity
- Explicit negation in patient facts (`ABSENT`, `NO`, `DENIES`, `NEGATIVE`) must never be converted into positive clinical facts.
- A claim asserting the presence of a negated concept is classified as `CONTRADICTED` (`ContradictionStatus.ASSERTION_CONFLICT`, Error $H6$).

### 4.2 Epistemic Missingness
- Missing information must remain `UNKNOWN` in criterion conclusions.
- A claim asserting that an unmentioned concept satisfies an inclusion criterion is classified as `UNSUPPORTED_ELIGIBILITY_CONCLUSION` ($H8$).

### 4.3 Temporal Uncertainty
- Time intervals must not fabricate calendar dates. If a clinical note states "diagnosed roughly two years ago," reasoning that asserts "diagnosed on 2024-03-15" is flagged as `H4_FABRICATED_TEMPORAL_FACT`.
- Relative temporal qualifiers (`prior to platinum therapy`) must strictly match the therapeutic sequence.

### 4.4 Numerical & Unit Integrity
- Numerical measurements must preserve their associated physical or clinical units.
- An assertion of `7.2` without units when the criterion demands `HbA1c < 8%` is valid only if contextual lab type is clear; changing `1.5 mg/dL` to `15 mg/dL` or omitting decimal points is flagged as `H3_FABRICATED_NUMERICAL_VALUE` (`ContradictionStatus.NUMERICAL_CONFLICT`).

## 5. Grounding Decision Algorithm

For any extracted claim $c$ and available evidence corpus $\mathcal{E} = \{e_1, e_2, \dots, e_n\}$:

```text
1. If c asserts that information is missing or uncertain,
   and no evidence in E affirms or refutes the topic:
   --> Return INSUFFICIENT_EVIDENCE

2. For each evidence item e in E:
   a. If e directly contradicts c (opposite assertion, conflicting number, conflicting date):
      --> Return CONTRADICTED (Conflict Type: DIRECT / ASSERTION / NUMERICAL / TEMPORAL)

3. For each evidence item e in E:
   a. If e fully entails c (concept matches, assertion matches, numbers/dates align):
      --> Return SUPPORTED (Attach supporting_evidence_id = e.evidence_id)
   b. If e partially entails c (core concept matches but qualifier unverified):
      --> Candidate for PARTIALLY_SUPPORTED

4. If partial entailment found and no contradiction:
   --> Return PARTIALLY_SUPPORTED

5. Otherwise (no entailing or contradicting evidence):
   --> Return UNSUPPORTED (Map to Hallucination Taxonomy H1-H5, H8, H10)
```
